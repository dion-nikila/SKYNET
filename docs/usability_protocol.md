# SKYNET Lightweight Usability Evaluation Protocol (Pilot)

## Purpose
Provide preliminary, structured evidence that SKYNET is readable and usable by non-technical users.

## Study type
- Small pilot usability evaluation (task-based)
- Recommended participants: 5 to 10
- Suggested profile: mixed technical background

## Materials
- Task sheet: `docs/usability_tasks_template.csv`
- Survey sheet: `docs/usability_survey_template.csv`
- Findings summary: `docs/usability_findings_template.md`

## Procedure (per participant)
1. 3-minute orientation to dashboard purpose.
2. Participant performs each task without intervention unless blocked.
3. Observer records completion status, time, and confusion points.
4. Participant completes post-task survey.
5. Observer records key quotes and top issues.

## Core evaluation questions
- Can users run a baseline forecast without guidance?
- Can users distinguish macro scenario, guided intervention, and manual custom what-if?
- Do users understand reliability guidance vs empirical uncertainty ranges?
- Can users interpret what changed between baseline and scenario?
- Can users export a result for reporting?

## Honesty constraints for report
- Do not fabricate participant data.
- If no study is completed, report this as "protocol and instruments prepared; formal validation pending." 
- If pilot is completed, report sample size and limitations clearly.
